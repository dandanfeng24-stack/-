# 财富路径引导 App - 登录版静态原型

## 产品逻辑

- 未注册用户：可以完整浏览赚钱方案库和分类筛选结果。
- 注册用户：进入客户数据库，可收藏方案、领取资料、查看用户中心记录。
- 管理员：可查看客户数据库、注册人数、登录次数、收藏和资料领取数据。

## 新增功能

- 注册页：`register.html`
- 登录页：`login.html`
- 用户中心：`profile.html`
- 资料领取：`resources.html`
- 管理员统计：`admin.html`
- 方案收藏
- 资料领取记录
- 登录人数、注册人数、收藏数、下载数统计
- 运营数据导出

## 重要说明

这是静态原型版，用户数据保存在浏览器 localStorage 中。

适合：
- 本地测试产品流程
- 演示注册、登录、收藏、资料分发、统计逻辑
- 判断下一步是否接真实后台

不适合：
- 正式收集真实用户密码
- 线上商用注册系统
- 多设备同步用户数据
- 严格权限管理

正式上线时需要接入：
- Supabase / Firebase / 腾讯云 CloudBase / 自建后端
- 密码加密
- 手机号或邮箱验证
- 隐私政策和用户协议
- 数据库和后台权限


浏览器打开：

```txt
https://caifu-path.vercel.app/index.html
```
